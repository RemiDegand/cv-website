Zone after zone, every week: about 2 h of typing what was already written.

Adjustments already written in sentences had to reach the forecasting tool without being typed again.

Context

Glovo's forecasting team updated the rider supply forecast every week. At the start of the week, it analysed past performance and collected inputs from the local teams; at the end, it decided on adjustments and entered them in a Google Sheet with Apps Script, connected to BigQuery.

The problem

  • Repetitive: for each zone, select it, type every adjusted value in the hour-by-day grid, save with a button, then start again with the next zone.
  • About 2 h every week, before exporting the final sheet into the company's forecasting tool.
  • Double work: the same adjustments were already written in sentences for the local teams.

What I built: an AI skill for the forecasting team

The process: before and after

Before

  1. Pick a zoneCurrent values loaded from BigQuery
  2. Type the gridEach new value, hour by hour and day by day
  3. Save adjustmentsButton "Add Adjustments", to save them in another sheet in the right format
  4. ↺ Repeat for each zone
  5. ExportThe final sheet, exported into the forecasting tool

After

  1. Send adjustments through sentences to the AIThe ones already written for the local teams
  2. The AI calculates and formatsA new value for each zone, day and hour, in the right format
  3. Export readyFinal CSV, exported into the forecasting tool

How the AI calculates: what it is given

  1. BigQuery accessTo read the current values of each zone
  2. The right queryTo get the current UTR by zone, day and hour
  3. A promptRules + examples of how to describe a sentence, to get the right format
  4. JSON codeTo do the calculation, so each new value is calculated, not guessed

The skill was on GitHub, so anyone on the forecasting team could use it.

Impact & tools

Impact

  • ~2 h a week of manual entries handed to the AI: the forecaster only pastes the sentences and downloads the file.
  • Fewer errors: no values typed by hand, calculations based on the real data, and a fixed output format.
  • For the whole team: the skill is shared on GitHub and used by every forecaster.

Tools

  • LLMs (Gemini, Claude)
  • AI agents (OpenCode)
  • Prompt engineering
  • BigQuery (SQL)
  • GitHub
