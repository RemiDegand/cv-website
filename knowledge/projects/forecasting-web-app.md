# Forecasting web app (Glovo)

## Summary
The forecasting web app is an internal tool Rémi designed and built during the Glovo internship to improve forecast accuracy. It combines multi-view dashboards, AI-generated summaries for each zone and a chatbot, and is used daily by all forecasting team members across 3 regions (Europe, Africa, Asia).

## Context
Rémi was Forecasting Analyst Intern in Glovo's Global Operations, in the Supply Ops department, working on the PLECA market (Poland, Kazakhstan, Kyrgyzstan, Georgia, Armenia, Ukraine). Rémi forecast weekly rider supply for 5 countries (South Poland, West Ukraine, Armenia, Georgia, Kyrgyzstan), covering about 615K orders and 371K rider slots per week, to match rider availability with customer demand. The web app was built alongside this forecasting work.

## What I built
A web app for the forecasting team, with:
- multi-view dashboards covering the 3 regions (Europe, Africa, Asia);
- AI-generated summaries for each zone;
- a chatbot built into the app.

## Results and impact
- Used daily by all forecasting team members (all forecasters across Europe, Africa and Asia).
- Context figure for the role (not measured for the app alone): Rémi reached 58% forecast accuracy, 8 points above the 50% target, by reviewing past forecasts to fix gaps and leading weekly meetings with the 5 local teams.

## Users
All forecasters of the global forecasting team, across Europe, Africa and Asia; daily use.
