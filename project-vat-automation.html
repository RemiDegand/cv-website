Problem & context

How it started

ManagerIs this month's VAT ready?

AccountantNot yet, I'm still copying the supplier invoices one by one.

ManagerAgain? It's like that every month.

Accountant

A monthly task done by hand had to become automatic.

Context

Every month, OSLO's accounting department calculated the VAT of each VAT account on the supplier entries of journal A1 that were not yet matched, in an Excel file filled in by hand.

The problem

  • Manual entries: each invoice amount was copied one by one to add up the VAT.
  • Every month: time spent on a low-value task.
  • Error-prone: the calculation was hard to trust.
2

Part 2 of 3

What I built: an Excel file connected to the ERP, and a macro

The process: before and after

Before

  1. Find the entriesUnmatched supplier entries of journal A1
  2. Copy each amountInvoice by invoice, into Excel
  3. Add up the VATFor each VAT account, by hand

After

  1. RefreshMyReport extracts the right entries from the ERP
  2. Click "Assign VAT"The macro fills each VAT column and freezes the data
  3. VAT readyBy VAT account, with the BU, entry number and supplier

Built withETL from the ERPData model with filtersVAT by entryVBA macro

Impact & tools

Impact

  • 1 h 30 saved every month (estimate).
  • No more manual entries: fewer errors, and a VAT calculation the accounting department can rely on.
  • A month stays as calculated: frozen values are not changed by later updates in the ERP.

The monthly VAT process is automated, more reliable and secure.

Tools

  • Excel
  • MyReport Data (ETL, Data modeling)
